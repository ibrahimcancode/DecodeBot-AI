# Hidden Commands & Easter Eggs

These commands are not shown in the `help` output but are functional.

| Command | Effect |
|---------|--------|
| `tell me a joke` / `joke` | Returns a random programming joke |
| `are you sentient` / `are you alive` / `are you skynet` | Self-awareness gag response |
| `up up down down` | Konami-style easter egg |
| `do a barrel roll` | Fun animation response |
| `hello world` | Programmer greeting |
| `forget my name` / `forget me` | Clear stored user name |
| `set name <X>` / `call me <X>` | Set user name explicitly |
| `dumpstate` | (developer mode) Print session state |
| `listplugins` | (developer mode) List loaded plugins |
